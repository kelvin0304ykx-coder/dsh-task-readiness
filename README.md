# DSH 功能体检助手

面向普通用户的任务就绪检查插件项目。目标是让用户知道当前会话能做什么、缺什么、如何补齐，并为诊断结论保留可核验依据。

## 当前状态

2026-11-13 已完成初版完整设计和 DSH 0.2.2-rc.2 的关键接口核验。16 项实际 SDK 方法的隔离合成测试通过。尚未实现产品插件，没有可安装版本，未向日常 DSH 环境部署。

## 阅读入口

- [完整版设计](<docs/完整版设计.md>)：自然语言与任务入口、六类能力、状态协议、探测、受控处理、访问边界、验收和工程拆分。
- [接口核验记录](<docs/接口核验记录.md>)：精确版本来源、公开接口定位、已执行测试和未验证部分。
- [原始探针结果](<research/contract-probe-results.json>)：16 项隔离方法测试，不是产品端到端验收。

## 下一步

确认完整设计，尤其是首发受控处理范围，然后编制实现计划并在隔离环境开发。产品第一版同时包含自然语言与常用任务入口；不把安装成功等同于能力就绪，不把诊断通过等同于任务正确。

研究资料来自精确版本官方 SDK，仅用于本地接口验证。公开发布前另行确认包名、许可证、兼容版本和发布范围，不将此目录整体直接上传。

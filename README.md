# DSH 功能体检助手

开工前先确认“这个会话现在到底能不能做这件事”。面向普通用户，不替代宿主权限，也不把诊断通过当成任务质量或安全保证。

当前版本：0.1.0-preview.1，宿主基线 DSH 0.2.2-rc.2。未发布，未安装到任何日常 profile。

## 它做什么

- 把一句任务描述或内置模板变成结构化的能力要求（联网搜索、网页抓取、读写文件、读图、Office 生成/预览/转换/重算、浏览器读取、MCP）。
- 只读采集本轮证据：工具准入、捕获的模型路由、工作目录、沙箱写入边界、审批策略、文档引擎服务、MCP 可见性、显式输入文件。
- 给出逐项状态：具备条件但未测试、指定测试通过、已知阻塞、待确认、证据过期；未知不会被写成通过。
- 可选最小探测：文件读取、文件写入（创建并删除唯一合成文件）、固定示例页抓取、一次有上限的检索、合成文档的转换/渲染/工作簿重算。
- 受控处理：本插件自有任务选项的输出目录、替代路线与恢复；执行前必须由宿主审批返回 allowed-once。
- 复检：任何动作之后重新采集证据并生成新报告，旧报告保留为历史。

## 三个工具

| 工具 | 作用 | 边界 |
|---|---|---|
| `readiness_check` | 校验任务意图并生成报告 | 只读，不联网测试、不执行任务、不改配置 |
| `readiness_probe` | 生成或执行最小探测 | 只接受内置探测；执行需要宿主审批；超时或取消保留未知 |
| `readiness_remedy` | 生成或执行受控处理 | 只改本插件自有选项；不改宿主模型、权限或其它插件配置 |

命令：`/readiness`、`/readiness-list`、`/readiness-refresh`。命令入口没有本轮工具准入与审批，因此只读，不发起探测。

## 探测支持矩阵

| 能力 | 自动探测 | 说明 |
|---|---|---|
| 读取文件 | 是 | 对显式声明输入读取受限字节窗口 |
| 写入目标目录 | 是 | 在所选目录创建并立即删除唯一合成文件，经过宿主权限边界 |
| 网页抓取 | 是 | 固定示例页，校验状态码与正文标记，验证码页判为失败 |
| 联网搜索 | 是 | 一次有上限、非敏感的查询，费用未知时显示费用未知 |
| 文档转换 / 页面渲染 / 表格重算 | 是 | 使用随包合成文档经宿主文档引擎执行 |
| 文档生成 | 否 | 需要宿主 shell 与技能，本插件不代跑脚本 |
| 图片理解 | 否 | 需要新一轮模型请求与附件，本插件不代发模型请求 |
| 浏览器读取 | 否 | 需要调用当前会话的浏览器工具，本插件不直接执行工具 |
| MCP 连接 | 否 | 探测会连接并可能启动进程，本插件不代发 |

没有自动探测的能力会显示“未知”与人工验证办法，不会伪装成不支持或已通过。

## 安装（已在隔离 profile 验证安装与卸载，未验证启动挂载）

本包是一个 Cordis bundle：`package.json` 的 `dsh.bundle.patch` 指向 `cordis.patch.yml`，补丁插入一个名为 `dsh-task-readiness` 的插件条目。已在独立 `DSH_HOME` 中用宿主的 `dsh plugin --profile <name> add <tgz>` 完成安装：插件自动加入该 profile 的 bundle 列表，`dsh --profile <name> --dump-config` 能看到插入条目，`remove` 后条目消失。运行时不 import 任何宿主包，也不额外安装依赖。若要让插件在某个 profile 生效，仍需在该 profile 启动宿主，这一步本机未执行。

## 隐私与数据

- 诊断缓存只在内存中保留本会话的最小证据；不写整份环境变量、配置或会话内容。
- 动作日志只记录计划 id、会话 id、动作种类、绑定指纹、时间与结果，用于幂等与中断恢复，不记录任务正文、密钥或文件内容。
- 共享导出走白名单投影：不含会话 id、绝对路径、原始任务文本与错误正文。
- 探测使用随包合成材料，不发送用户文档。

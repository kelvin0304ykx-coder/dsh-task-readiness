## 二 版本与平台矩阵

- 宿主基线：DSH 0.2.2-rc.2（`engines.dsh` 精确匹配）。
- Node：>= 24。
- 运行时依赖：无。zod 已打包进 `lib/index.js`，不依赖 profile 的 peer 解析。
- 实测平台：macOS arm64（本机 App 0.2.2-rc.2）。
- 未实测：Windows、Linux、其他宿主版本。发布文案必须写明未验证范围，不能写“跨平台已支持”。

## 三 隐私与数据复核

- 动作日志只写计划 id、会话 id、动作种类、绑定指纹、时间与结果；不写任务正文、文件内容、路径、密钥。
- 报告内存上限 100 条、动作 100 条、探测证据 500 条；动作日志 500 条。
- 模型可见摘要去掉会话 id、绝对路径、原始任务文本；共享导出为白名单投影。
- 探测只用随包合成材料（docx/xlsx/png/txt）与固定示例页。
- 不收集遥测、不上传诊断、不内置反馈通道。
- 发布前再次搜索构建产物与 README 中的邮箱、密钥、绝对路径（`node scripts/check-package.mjs` 已包含）。

## 四 复现验证命令

在插件项目根目录（本机需已安装开发依赖）：

~~~sh
NODE=/Users/akai/.dsh/dsh-runtimes/dsh-primary-runtime/dependencies/node/bin/node
$NODE node_modules/typescript/bin/tsc --noEmit
$NODE --test tests/*.test.ts
$NODE scripts/build.mjs && $NODE scripts/check-package.mjs
$NODE scripts/smoke.mjs
pnpm probe        # 宿主 SDK 层探针（9 项）
pnpm probe:office # 真实文档引擎探针（7 项）
~~~

隔离安装与卸载（不启动宿主、不碰日常配置）：

~~~sh
rm -rf /tmp/dsh-verify && mkdir -p /tmp/dsh-verify/bin
printf '#!/bin/sh\nexec <node> <pnpm.mjs> "$@"\n' > /tmp/dsh-verify/bin/pnpm && chmod +x /tmp/dsh-verify/bin/pnpm
PATH=/tmp/dsh-verify/bin:$PATH DSH_HOME=/tmp/dsh-verify \
  ELECTRON_RUN_AS_NODE=1 '/Applications/DeepSeek Harness.app/Contents/MacOS/DeepSeek Harness' \
  '/Applications/DeepSeek Harness.app/Contents/Resources/app.asar/dsh/node_modules/@deepseek-ai/dsh/lib/bin.js' \
  plugin --profile readiness add "$PWD/dist/dsh-task-readiness-0.1.0-preview.1.tgz"
PATH=/tmp/dsh-verify/bin:$PATH DSH_HOME=/tmp/dsh-verify \
  ELECTRON_RUN_AS_NODE=1 '/Applications/DeepSeek Harness.app/Contents/MacOS/DeepSeek Harness' \
  '/Applications/DeepSeek Harness.app/Contents/Resources/app.asar/dsh/node_modules/@deepseek-ai/dsh/lib/bin.js' \
  --profile readiness --dump-config | tail -8
PATH=/tmp/dsh-verify/bin:$PATH DSH_HOME=/tmp/dsh-verify \
  ELECTRON_RUN_AS_NODE=1 '/Applications/DeepSeek Harness.app/Contents/MacOS/DeepSeek Harness' \
  '/Applications/DeepSeek Harness.app/Contents/Resources/app.asar/dsh/node_modules/@deepseek-ai/dsh/lib/bin.js' \
  plugin --profile readiness remove dsh-task-readiness
~~~

## 七 卸载与回滚

- 卸载：`dsh plugin --profile <name> remove dsh-task-readiness`，随后重启宿主。
- 回滚：重新 `add` 上一版本 tarball。
- 本插件不修改宿主全局模型、权限或其它插件配置；卸载不会影响它们。

# DSH 功能体检助手接口核验记录

核验日期：2026-11-13。目标：判断完整版产品设计能否使用公开接口实现，并区分源码依据、隔离方法测试和实际用户端验收。

## 一 结论

可以进入独立插件的实现设计。会话作用域、步骤工具准入、模型选择、沙箱策略、插件清单、Office 动态工具及 MCP 状态存在可利用接口，但不存在一个可直接返回“这个任务一定能做”的统一健康接口。

本轮完成 **16 项实际 SDK 方法的隔离合成测试，16 通过、0 失败**。这不是插件已实现、实际外部服务已连通或用户端 E2E 通过的证明。

## 二 核验环境与材料

- 本机 App 清单及随包运行时清单均为 0.2.2-rc.2；Cordis 4.1.0。
- 隔离测试使用本机 App 自带 Electron 的 Node 模式，Node v24.21.0，只导入 SDK 模块，不启动另一套 DSH Host。
- 从 npm 精确版本下载 16 个 SDK 包，在本项目研究目录校验 SHA-512 后，仅展开类型声明、清单与说明；没有安装到 profile，没有运行包安装脚本。
- 下载来源与摘要分别保存在[首批来源清单](<../research/sdk-0.2.2-rc.2/sources.json>)和[补充来源清单](<../research/sdk-0.2.2-rc.2/sources-extra.json>)。来源均为 npm 上的精确版本包，不是可漂移的 latest。
- 动态测试调用 App 分发的实际方法，外部依赖与 Agent 是合成输入。没有实例化生产服务，没有读取凭据、用户会话数据库或业务原件。
- 检查当前 SDK 绑定时，搜索、网页抓取、读图工具可见，Office 三个工具未出现；该观察仅表示工具声明可见性，见[当前工具观察](<../research/live-catalog-observation.json>)。不能据此宣称引擎缺失。

本机执行文件与 npm 类型包的版本已对齐；未做完整安装目录与 npm 全部字节等价审计。

| E16 | readPluginInventory 返回 Loader 与 preset 状态，不是任务可执行性 | [插件清单](<../research/sdk-0.2.2-rc.2/dsh-host-plugin-inventory/lib/types/index.d.ts>) | 清单只作为一类证据，不取代步骤工具集合 |
| E17 | Remote 通过受信 Peer、资源和 Context 绑定校验访问 | [Peer 身份](<../research/sdk-0.2.2-rc.2/dsh-typert-protocol/lib/types/types.d.ts#L352-L385>)、[资源解析](<../research/sdk-0.2.2-rc.2/dsh-api-gateway/lib/types/access.d.ts>) | 不把客户端 sessionId 当授权，集成阶段补全访问负例 |

不依赖 TypeScript 标为 private 的 selectSearchProvider、effectivePolicy 等作为产品 API。研究脚本为了隔离真实方法的控制流程，使用了合成内部依赖；这不构成产品调用私有方法的设计许可。

## 四 已执行的 16 项隔离测试

完整结果见[原始结果](<../research/contract-probe-results.json>)；脚本见[契约探针](<../research/contract-probe.mjs>)。

| 组 | 验证内容 | 数量 | 结果 |
|---|---|---:|---|
| 工具准入 | 注册不等于本轮可用；条件工具无步骤不能调用；跨 Agent 隔离；卸载、同名替换和 dispose 后旧准入失效；条件异常与取消；schema 不包含执行器 | 9 | 全部通过 |
| 网页准备状态 | 选择失败仍可 ready=true；明确 ready=false；缺少 ready 默认 true；fetch 404 不抛出 | 4 | 全部通过 |
| Office 动态工具 | 技能成功加载仅影响下一次准入，失败不激活；不影响其他 Agent；工具准入与引擎就绪分离 | 3 | 全部通过 |

这些测试通过，意味着上述真实 SDK 行为被复现，不意味着新插件的规则已经写完。测试未执行任何网络搜索、生图、模型推理、MCP 服务启动或真实文档转换。

复现方式在本机为：

~~~sh
ELECTRON_RUN_AS_NODE=1 '/Applications/DeepSeek Harness.app/Contents/MacOS/DeepSeek Harness' --expose-internals \
  'DSH-功能体检助手/research/contract-probe.mjs' \
  '/Applications/DeepSeek Harness.app/Contents/Resources/app.asar/dsh/node_modules/@deepseek-ai'
~~~

运行目录为本项目所在的上一级工作区。命令仅执行研究脚本，不启动 App 主界面或 DSH 服务。

## 五 仍待实现验证的部分

1. 在实际插件生命周期中捕获本轮模型与工具集，处理 HMR、重启和模型切换。

4. 对标准内置能力的实际合成文件、网页、浏览器与 MCP 测试，并核对费用和副作用。
5. 自有配置的可回滚事务、并发修改、幂等和故障恢复。

7. Windows 与 Linux 真实环境，不以 Mac 方法测试替代跨平台验收。
